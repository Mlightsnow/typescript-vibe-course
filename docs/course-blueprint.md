# 课程蓝图

## 定位

《Vibe Coding 时代的 TypeScript：从运行时到可靠全栈》面向有 Python/Java 基础但不熟悉 JavaScript，以及主要依赖 AI 编程的新学习者。主线约 20–30 小时。

学习者最终应该能够：

1. 判断 AI 生成代码的类型、运行时与测试证据是否成立；
2. 读懂并安全修改现有 TypeScript 与 React 项目；
3. 独立开发 REST、数据库、流式响应、任务队列组成的 Node.js 后端；
4. 从 SQLite 迁移到 PostgreSQL；
5. 接入 OpenAI 兼容 API，并把 SDK 事件隔离在自有适配层；
6. 在本地完成测试、日志、可观测性、构建和运行，不依赖 Docker。

## 第一性原理顺序

课程不从框架脚手架开始，而按以下依赖关系推进：

1. JavaScript 运行时决定真实行为；
2. TypeScript 把一部分不可能状态排除在源码之外；
3. 网络、配置、数据库和模型输出仍是不可信运行时边界；
4. HTTP、SSE、任务状态和工具调用首先是协议；
5. NestJS 把已经理解的协议映射为 Controller、Provider、Pipe、Filter 与 Interceptor；
6. 类型检查、运行时校验、测试、日志和 Trace 共同构成生产证据。

## 贯穿项目：CodePilot

CodePilot 是代码理解与审查助手，不是任意命令执行平台。它逐步支持：

- 创建项目、会话和审查任务；
- 流式展示文本与工具事件；
- 通过受约束的工具读取、搜索教学代码仓；
- 排队、取消、重试和恢复后台任务；
- 查看状态、结构化日志、耗时和 Trace ID；
- 通过轻量 React 客户端操作上述能力。

模型不能执行任意 Shell 或自动修改真实文件。最终只输出结构化 Patch 建议，由人审查。

## 章节路线

| ID | 时长 | 第一性问题 | CodePilot 增量 | 核心验收 |
|---|---:|---|---|---|
| M00 AI 写完后，人负责什么？ | 0.5h | 编译通过为何不等于正确？ | 初始化质量门禁 | 用 TRUST 找到五类虚假安全感 |
| M01 JavaScript 才是运行时 | 1.75h | `.ts` 最终由谁执行？ | 最小任务领域模型 | 修复共享引用、异常与模块副作用 |
| M02 异步不是语法糖 | 1.75h | `await` 在等待谁？ | 可取消 Mock token 流 | 证明取消后无增量、无 timer |
| M03 类型是值集合与约束 | 2.5h | 如何排除不可能状态？ | 任务与事件判别联合 | 消除布尔状态爆炸 |
| M04 从数据到可复用契约 | 2.5h | 泛型什么时候有约束价值？ | Repository、Model、Tool Ports | 删除无价值的泛型抽象 |
| M05 类型会消失，边界不会 | 1.75h | 为什么不能直接 `as`？ | 校验配置、DTO 与事件 | 删除不安全断言并补解析器 |
| M06 原生 HTTP、REST 与 SSE | 2.25h | 框架替我们做了什么？ | 原生任务 API 与事件订阅 | 证明断连取消下游 |
| M07 测试是行为证据 | 2h | 什么测试能因真实缺陷失败？ | 领域、HTTP、SSE 测试层次 | 改写伪测试与实现复刻测试 |
| M08 迁移到 NestJS | 2.25h | 框架概念映射到什么原理？ | 外部 API 不变，内部迁移 | 迁移前后契约测试一致 |
| M09 SQLite 数据边界 | 2h | TS 与 DB 约束各负责什么？ | 持久化项目、会话与任务 | 事务失败不产生半成品 |
| M10 真实模型与最小 Agent | 2.75h | SDK 类型为何不是业务协议？ | OpenAI 兼容流与只读工具 | 畸形事件、工具参数、路径穿越 |
| M11 后台任务与可靠性 | 2h | 请求结束后任务怎样继续？ | Worker、租约、重试与恢复 | 进程中断后不重复产出 |
| M12 PostgreSQL 与可观测性 | 2.25h | 跑通与可运营差在哪里？ | 多 Worker、日志和 Trace | 并发领取只能一个成功 |
| M13 React 阅读与修改 | 1.75h | UI 状态如何对应后端事件？ | 流式结果、取消和重试 UI | 改功能且不破坏错误态 |
| M14 综合交付 | 1.75h | 怎样证明功能值得合并？ | 跨 DB/API/Worker/UI 的策略功能 | 故障注入、回归与本地生产演示 |

主线总时长约 29.75 小时，扩展阅读不计入。

## 每章固定学习闭环

真实失败 → 运行前预测 → 第一性解释 → 最小实验 → CodePilot 增量 → AI Bad Case → TRUST 审查 → 自动验收 → 3–7 条带走规则。

代码块必须明确是完整程序还是片段；先显示可复现失败再给修复；`any`、`as`、非空断言、装饰器和 Mock 都要说明可信依据。
